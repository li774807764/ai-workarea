# AI 工作区 · 总纲

这套目录是「记忆与协作」的分层落地。六层：

| 层 | 目录 | 一句话 |
| --- | --- | --- |
| L0 宪法 | 总纲 | 谁说了算、什么不能改 |
| L1 共享 | 共享 | 技能、须知、看板、主画像 |
| L2 场景 | 场景 | 一个场景一套卡（定位卡/画像/私有记忆/技能/项目） |
| L3 个人 | 个人 | 个人资料，隔离，只有自我复盘能动 |
| L4 执行 | 执行 | 派单、回执、审计、运行时 |
| L5 归档 | 归档 | 只进不改 |

配套：项目（台账）、零件库（可复用件）、工具（脚本）、备份、仓库（远端）。

控制台：DSH 左侧栏「控制台」（插件 @local/workdesk）。
