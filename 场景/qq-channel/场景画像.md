# 场景画像：QQ 通道

- 窗口：左侧栏「QQ」绑定面板（扫码 / 手动连接 / 账号状态 / 最近日志）。
- 管目录：`~/.dsh/plugins/dsh-qqchat`；sessions 落 `~/.dsh/sessions\--C-Users-Administrator-.dsh-profiles-desktop--\qqchat-*`。
- 关键补丁：`agent-bridge.js` 的 snapshot source 用 `runtime-context`（v4 消息格式拒绝 `plugin`）；会话挂到 QQ 专属工作区；followup 前解归档。
- 不做：不让 bot 服务他人；不把 QQ 会话上下文当成网页会话。
